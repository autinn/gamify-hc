HARD CONCEPT 1: #complexcausality
================================================================================
Definition: Identify how multiple causes interact to produce complex effects.

Question 1:
Q: A polar region experiences accelerating ice melt: as sea ice disappears, darker ocean water absorbs more heat, further speeding melting. Which best describes this interaction?
A) Linear causation
B) Random correlation
C) Reinforcing feedback loop ✓
D) Isolated cause–effect chain
Explanation: Reinforcing loops amplify change within a system through interconnected causes.

Question 2:
Q: A city introduces free gym memberships to reduce obesity, but finds little effect because fast-food density and work stress remain high. What does this illustrate?
A) A single sufficient cause
B) Interacting causal factors that offset each other ✓
C) A non-causal coincidence
D) Random variance
Explanation: Multiple interacting causes can neutralize one another, showing complex causality.

Question 3:
Q: After adding a new bus line, traffic worsens because fewer people carpool and more use feeder roads. Which HC concept explains this?
A) Emergent property
B) Complex causality ✓
C) Network hub effect
D) System mapping

A) It addressed only one pathway in a multi-causal system ✓

A) Direct linear reduction
B) Unintended rebound effect via interacting variables ✓

A) Class size is the sole cause of outcomes

A) Temporal lag between intervention and measurable outcome ✓

HARD CONCEPT 5: #systemdynamics
================================================================================
Definition: Use the tools of phase spaces--including attractors, critical points, and basins--to describe and predict the ways a complex system changes over time.

Question 1:
Q: A struggling town invests in beautification, triggering local employment and attracting business until prosperity stabilizes. What phase-space element describes the final state?
A) Critical point
B) Attractor ✓
C) Feedback loop
D) Variable shift
Explanation: An attractor is a stable equilibrium toward which the system moves.

Question 2:
Q: An individual's sleep and stress stabilize only after reaching a tipping point of lifestyle adjustments. This tipping point represents:
A) Attractor basin
B) Critical point ✓
C) Random shock
D) Feedback error
Explanation: Crossing a critical point shifts the system into a new regime.

Question 3:
Q: Global warming accelerates beyond 1.5 °C, leading to irreversible ice-sheet loss. Which concept captures this transition?
A) Stable basin
B) Critical threshold between basins ✓
C) Emergent property
D) Linear trend
Explanation: Crossing a threshold between basins changes the system's trajectory.

Question 4:
Q: A lake ecosystem alternates between clear water with abundant plants and murky water dominated by algae. Small nutrient increases have little effect until a threshold triggers regime shift. What describes these two stable states?
A) Random fluctuations
B) Alternative attractors in different basins ✓
C) Linear progressions
D) Temporary deviations
Explanation: Alternative attractors represent distinct stable states; systems can flip between them when pushed past critical thresholds.

Question 5:
Q: A rehabilitation program shows that patients with moderate initial improvements tend to continue recovering, while those with minimal early progress often relapse. What phase-space concept explains this pattern?
A) Uniform change across all states
B) Basins of attraction pulling toward different outcomes ✓
C) Random treatment responses
D) Linear dose-response relationship
Explanation: Initial conditions determine which basin (recovery vs. relapse) a patient falls into, shaping long-term trajectory.

Question 6:
Q: A financial market oscillates between boom and bust cycles, stabilizing temporarily in each state before external shocks trigger transitions. Which system dynamics framework applies?
A) Simple linear growth
B) Multiple attractors with perturbation-driven transitions ✓
C) Continuous smooth progression
D) Isolated variables
Explanation: Markets exhibit multiple stable attractors; shocks can push the system across thresholds into new regimes.

Question 7:

A) Gradual linear increase in fire size
B) Crossing a critical point leading to regime change ✓

D) Reversible temperature effect
Explanation: Small parameter changes can trigger large qualitative shifts when systems cross critical thresholds.

Question 8:
Q: A social network platform remains stable with moderate user engagement for years. Suddenly, a viral feature causes explosive growth, then stabilizes at a much higher equilibrium. What phase-space elements are involved?
A) Only one stable state exists
B) Transition from one attractor to another via critical point ✓
C) Purely random growth patterns
D) Linear user accumulation
Explanation: The system moved from one stable state (low engagement) through a critical transition to a new attractor (high engagement).

Question 9:
Q: Urban planners observe that neighborhoods with 15% green space tend to decline in quality over time, while those with 25% green space tend to improve. The 20% threshold marks a transition point. What best describes this?
A) Green space has no systematic effect
B) A critical point separating two attractor basins ✓

Question 10:
Q: A species population remains stable at low levels despite conservation efforts. After habitat restoration crosses a threshold, population rapidly grows and stabilizes at carrying capacity. Which concepts apply?
A) Simple linear growth from conservation
B) Critical point triggering transition between population attractors ✓
C) Random population fluctuation
D) Conservation has no effect
Explanation: The system was trapped in a low-population attractor; crossing the critical threshold enabled transition to a high-population stable state.

D) By budget size
Explanation: The chosen deconstruction must best address the explanatory challenge.

A) Clear functional decomposition ✓

C) Focus on causal loops
