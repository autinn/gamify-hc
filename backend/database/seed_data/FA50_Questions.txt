HARD CONCEPT #1: #algorithms
================================================================================
Definition: Apply algorithmic thinking strategies to solve problems and effectively implement working code.

---
Question 1:
You design a returns-intake process: input = item + receipt; steps = validate → route by condition → restock/dispose; output = disposition label. What's missing for a robust algorithm?

A) More condition branches
B) Termination and explicit error handling for missing receipt ✓
C) A fancier flowchart tool
D) Converting to recursion

Explanation: Good algorithms are finite and handle failures/edge cases explicitly.

---
Question 2:
You must assign 1,200 riders to 1,200 scooters minimizing total walking distance on a grid. Best first strategy?

A) Brute-force all matchings
B) Use a polynomial-time assignment algorithm (Hungarian) ✓
C) Greedy nearest-neighbor only
D) Depth-first search over all permutations

Explanation: This is a classic assignment problem; Hungarian beats brute/greedy here.

---
Question 3:
A sorting routine works on random arrays but fails on arrays with all equal values. Best test design fix?

A) Larger random arrays
B) Systematic unit tests covering edge classes: empty, single, sorted, reverse, all-equal ✓
C) Rename variables clearly
D) Measure Big-O only

Explanation: Robustness comes from targeted edge-case coverage.

---
Question 4:
An algorithm must process a list of transactions and flag duplicates. What are the essential components?

A) Only input and output
B) Clear input, step-by-step procedure, termination condition, and defined output ✓
C) Just a flowchart
D) Any working code

Explanation: Algorithms require: well-defined inputs, unambiguous steps, guaranteed termination, and clear outputs.

---
Question 5:
A search algorithm must find a student record in a database of 100,000 entries. Comparing binary search (O(log n)) vs. linear search (O(n)), which is more efficient?

A) Linear search, because it's simpler
B) Binary search, because it examines far fewer entries ✓
C) Both are equally efficient
D) Efficiency doesn't matter with modern computers

Explanation: Binary search requires ~17 comparisons vs. up to 100,000 for linear search, demonstrating algorithmic efficiency.

---
Question 6:
You write an algorithm to calculate factorial recursively but it crashes on large inputs. What's likely missing?

A) Base case to ensure termination ✓
B) More recursion
C) Faster hardware
D) Better variable names

Explanation: Recursive algorithms need explicit base cases to terminate; without them, they recurse infinitely.

---
Question 7:
An algorithm sorts data correctly but takes hours on 10,000 items. What should you analyze?

A) Only correctness matters
B) Time complexity—the algorithm may be inefficient (e.g., O(n²) instead of O(n log n)) ✓
C) Variable naming only
D) Code formatting

Explanation: Time complexity determines scalability; inefficient algorithms become impractical with larger inputs.

---
Question 8:
Which demonstrates decomposition in algorithmic thinking?

A) Writing one large function to do everything
B) Breaking "process order" into: validate payment, update inventory, send confirmation ✓
C) Avoiding modularity
D) Using only loops, no functions

Explanation: Decomposition breaks complex problems into manageable subproblems, each solvable by simpler algorithms.

---
Question 9:
An algorithm must handle edge cases: empty input, single item, and maximum capacity. Why is this important?

A) Edge cases are rare and can be ignored
B) Robust algorithms handle boundary conditions explicitly to prevent failures ✓
C) Edge cases only matter for testing
D) Algorithms should crash on edge cases

Explanation: Edge cases expose algorithmic weaknesses; explicit handling ensures reliability in real-world conditions.

---
Question 10:
You design a route-planning algorithm. It produces correct paths but sometimes runs indefinitely on circular routes. What's the fix?

A) Add more conditions randomly
B) Implement cycle detection and termination conditions ✓
C) Ignore the problem
D) Use faster hardware

Explanation: Algorithms must guarantee termination; cycle detection prevents infinite loops in graph traversal.

HARD CONCEPT #2: #estimation
================================================================================
Definition: Use estimation and approximation techniques appropriately.

---
Question 1:
A venue fits between 400–1,600 people. Midpoint for order-of-magnitude planning?

A) 1,000 (arithmetic mean)
B) 800 (geometric mean proxy between 4×10² and 16×10²) ✓
C) 500
D) 1,600

Explanation: When bounds span factors, geometric mean better centers magnitude.

---
Question 2:
Estimate daily coffee cups sold by 50 campus cafés. First step?

A) Ask one barista
B) Break into cafés × hours open × customers/hour × cups/customer with unit tracking ✓
C) Check last year's invoice total
D) Assume 1,000 per café

Explanation: #breakitdown + unit consistency → defensible Fermi.

---
Question 3:
Your time-to-finish estimate ignores context-switching overhead. Which bias likely?

A) Base-rate fallacy
B) Planning fallacy / optimism bias ✓
C) Gambler's fallacy
D) Survivorship bias

Explanation: Systematic underestimation = classic planning fallacy.

---
Question 4:
Estimate how many piano tuners work in Chicago. Which approach applies Fermi estimation?

A) Look up the exact number
B) Estimate: population → households → pianos → tunings/year → tuner capacity ✓
C) Guess randomly
D) Assume it's unknowable

Explanation: Fermi estimation decomposes unknowns into estimable factors, multiplying reasonable approximations.

---
Question 5:
You need to estimate project completion time. Historical similar projects took 8, 10, and 15 weeks. What's a reasonable estimate?

A) Exactly 8 weeks (minimum)
B) 10-12 weeks, accounting for typical overruns ✓
C) Exactly 15 weeks (maximum)
D) 1 week with aggressive timeline

Explanation: Reference class forecasting uses historical data; median with buffer accounts for planning fallacy.

---
Question 6:
Estimate the weight of a blue whale without scales. Which method is most appropriate?

A) Pure guessing
B) Use volume estimation (length × width × depth) × water density, then adjust ✓
C) Ask for opinions and average them
D) It cannot be estimated

Explanation: Physical estimation uses dimensional analysis and known constants to approximate unknowns.

---
Question 7:
When is a rough estimate (order of magnitude) sufficient vs. precise calculation?

A) Precise calculation is always necessary
B) Rough estimates suffice for feasibility checks; precision needed for final decisions ✓
C) Estimates are never useful
D) Precision doesn't matter

Explanation: Estimation helps evaluate options quickly; precision matters when committing resources.

---
Question 8:
You estimate server capacity needs by multiplying: users × requests/user × data/request. One factor is off by 10x. What happens?

A) The error cancels out
B) The final estimate is off by ~10x, potentially causing over/under-provisioning ✓
C) It doesn't matter
D) The estimate becomes more accurate

Explanation: Errors in component estimates compound multiplicatively; large errors in any factor dominate.

---
Question 9:
A city plans to estimate water usage. They have: population, average household size, and per-capita consumption data. What estimation technique applies?

A) Bottom-up decomposition using available parameters ✓
B) Pure intuition
C) Wait for perfect data
D) Random sampling only

Explanation: Bottom-up estimation combines known quantities to approximate the target value.

---
Question 10:
Why round intermediate estimates to 1-2 significant figures in Fermi calculations?

A) To introduce errors deliberately
B) False precision is misleading; rounding acknowledges uncertainty ✓
C) Exact numbers are always better
D) Rounding makes math harder

Explanation: Fermi estimation uses rough approximations; spurious precision implies accuracy that doesn't exist.

HARD CONCEPT #3: #deduction
================================================================================
Definition: Analyze and apply deductive reasoning.

---
Question 1:
All A are B. All B are C. Therefore all A are C. This is:

A) Valid; soundness depends on truth of premises ✓
B) Sound regardless
C) Inductive
D) Invalid

Explanation: Form guarantees validity; soundness needs true premises.

---
Question 2:
¬Q; P → Q; therefore ¬P. This is:

A) Modus ponens
B) Modus tollens ✓
C) Disjunctive syllogism
D) Non sequitur

Explanation: Deny consequent → deny antecedent.

---
Question 3:
Which equivalence is correct?

A) ¬(P ∨ Q) ≡ ¬P ∨ ¬Q
B) ¬(P ∧ Q) ≡ ¬P ∨ ¬Q ✓
C) ¬(P ∧ Q) ≡ ¬P ∧ ¬Q
D) P → Q ≡ P ∧ ¬Q

Explanation: First De Morgan law shown in (B).

---
Question 4:
If it rains, the game is cancelled. It is raining. Therefore:

A) The game might be cancelled
B) The game is cancelled ✓
C) The game continues
D) Nothing follows

Explanation: Modus ponens: P → Q; P; therefore Q.

---
Question 5:
All programmers know logic. Alice knows logic. Therefore Alice is a programmer. This reasoning is:

A) Valid
B) Invalid—affirming the consequent ✓
C) Sound
D) Modus ponens

Explanation: From P → Q and Q, you cannot conclude P. Others who aren't programmers may also know logic.

---
Question 6:
Either the server is down or the network is slow. The server is not down. Therefore:

A) Both are down
B) The network is slow ✓
C) Nothing follows
D) The server is fast

Explanation: Disjunctive syllogism: P ∨ Q; ¬P; therefore Q.

---
Question 7:
What makes deductive reasoning different from inductive reasoning?

A) Deduction is always wrong
B) Deduction guarantees the conclusion if premises are true; induction provides probable conclusions ✓
C) Induction is always better
D) They are identical

Explanation: Deduction is truth-preserving; valid deductive arguments cannot have true premises and false conclusions.

---
Question 8:
If a number is divisible by 6, it is divisible by 3. The number 18 is divisible by 6. What follows deductively?

A) Nothing certain
B) 18 is divisible by 3 ✓
C) 18 might not be divisible by 3
D) 18 is not divisible by 3

Explanation: Modus ponens applied to mathematical facts yields certain conclusions.

---
Question 9:
All arguments with true premises and valid form are:

A) Invalid
B) Sound ✓
C) Inductive
D) Fallacious

Explanation: Soundness = validity + true premises.

---
Question 10:
Given: All mammals are warm-blooded. Whales are mammals. What can be deduced?

A) Whales might be warm-blooded
B) Whales are warm-blooded ✓
C) Whales are cold-blooded
D) Nothing certain

Explanation: Categorical syllogism: All A are B; C is A; therefore C is B.

HARD CONCEPT #4: #fallacies
================================================================================
Definition: Identify and correct logical fallacies.

---
Question 1:
"If remote work increases, cities die. Cities aren't dying, so remote work isn't increasing."

A) Modus tollens
B) Denying the consequent? (No—actually affirming the negation incorrectly) → Affirming the negation / Invalid converse-style reasoning ✓
C) Sound argument
D) Straw man

Explanation: From ¬Q infer ¬P given only P→Q is invalid unless Q→P also holds.

---
Question 2:
"No study proves aliens don't exist; therefore aliens exist."

A) Red herring
B) Appeal to ignorance ✓
C) Bandwagon
D) Slippery slope

Explanation: Absence of disconfirming evidence ≠ evidence of truth.

---
Question 3:
"Don't trust her inflation analysis—she once misreported her taxes."

A) Weak analogy
B) Ad hominem (abusive/circumstantial) ✓
C) False dichotomy
D) Questionable cause

Explanation: Attacks person, not the argument.

---
Question 4:
"If we allow students to redo exams, soon they'll demand unlimited retakes and academic standards will collapse."

A) Slippery slope ✓
B) Straw man
C) False dichotomy
D) Appeal to authority

Explanation: Assumes one step inevitably leads to extreme consequences without justification.

---
Question 5:
"Everyone is switching to electric cars, so you should too."

A) Ad hominem
B) Bandwagon (appeal to popularity) ✓
C) Red herring
D) Circular reasoning

Explanation: Appeals to popularity as evidence rather than merit.

---
Question 6:
"We must choose between complete freedom or total government control."

A) False dichotomy (false dilemma) ✓
B) Slippery slope
C) Appeal to ignorance
D) Circular reasoning

Explanation: Presents only two options when more exist; ignores middle ground.

---
Question 7:
"This medicine works because it has healing properties." What fallacy?

A) Circular reasoning (begging the question) ✓
B) Straw man
C) Ad hominem
D) Appeal to authority

Explanation: The conclusion ("works") is restated in the premise ("healing properties") without independent evidence.

---
Question 8:
"A famous actor endorses this investment strategy, so it must be sound."

A) Hasty generalization
B) Appeal to false authority ✓
C) Slippery slope
D) Post hoc

Explanation: Appeals to authority outside their area of expertise; actors aren't financial experts.

---
Question 9:
"After the mayor took office, crime increased. Therefore, the mayor caused the crime increase."

A) Post hoc ergo propter hoc (false cause) ✓
B) Circular reasoning
C) Straw man
D) Appeal to ignorance

Explanation: Assumes temporal sequence implies causation without ruling out other factors.

---
Question 10:
"You say we should reduce carbon emissions, but you drove here in a car!"

A) Tu quoque (appeal to hypocrisy) ✓
B) Bandwagon
C) False dichotomy
D) Slippery slope

Explanation: Dismisses an argument by pointing out the arguer's inconsistency rather than addressing the argument's merit.

HARD CONCEPT #5: #induction
================================================================================
Definition: A method of reasoning where probable conclusions are drawn based on specific evidence and observations.

---
Question 1:
"Past 10 quarters: coupon users have 15–20% higher basket size; next quarter coupons will likely raise basket size."

A) Authority
B) Prediction from past data ✓
C) Analogy
D) Deduction

Explanation: Temporal generalization.

---
Question 2:
Anecdotes → strong generalization requires:

A) Louder claims
B) Larger, representative samples; multiple evidence types; narrower claims ✓
C) Only expert quotes
D) One perfect case study

Explanation: Quantity + quality + scope fit.

---
Question 3:
A strong meta-analysis relies on:

A) P-values only
B) True/accurate premises: good data, low bias, correct methods (#sourcequality) ✓
C) Persuasive writing
D) Single-lab replication

Explanation: Reliability = strong + true premises.

---
Question 4:
Every swan observed in Europe for 1,000 years was white. Conclusion: "All swans are white." What happened when explorers found Australia?

A) The inductive conclusion was proven certain
B) Black swans disproved the generalization, showing induction's limits ✓
C) The observations were irrelevant
D) Deduction would have failed too

Explanation: Induction provides probability, not certainty; new evidence can overturn generalizations.

---
Question 5:
A doctor observes that 95% of patients with symptom X have disease Y. A new patient presents with symptom X. What can be inferred?

A) The patient definitely has disease Y
B) The patient probably has disease Y ✓
C) The patient definitely does not have disease Y
D) No inference is possible

Explanation: Inductive reasoning from statistical patterns yields probable, not certain, conclusions.

---
Question 6:
What strengthens an inductive argument?

A) Smaller sample size
B) Larger, more representative sample and consistent patterns ✓
C) Ignoring counterexamples
D) Emotional appeals

Explanation: Inductive strength increases with sample size, representativeness, and pattern consistency.

---
Question 7:
A company finds that their top 5 salespeople all started in customer service. They conclude: "Customer service experience makes great salespeople." What could weaken this induction?

A) The sample is too small and may not be representative ✓
B) This is deductive, not inductive reasoning
C) The conclusion is definitely false
D) Induction cannot be weakened

Explanation: Small samples and selection bias weaken inductive generalizations.

---
Question 8:
"The sun has risen every day for billions of years, so it will rise tomorrow." This is:

A) Deductively certain
B) A strong inductive inference based on consistent patterns ✓
C) A fallacy
D) Impossible to evaluate

Explanation: Induction from overwhelming consistent evidence yields high confidence, though not logical certainty.

---
Question 9:
Scientific theories are supported by:

A) Pure deduction from axioms
B) Inductive reasoning from repeated observations and experiments ✓
C) Personal beliefs only
D) Authority alone

Explanation: Science uses induction: generalizing from observed instances to form theories, which remain probabilistic.

---
Question 10:
A survey of 10,000 voters shows 52% support a candidate. Conclusion: "The candidate will likely win." What makes this induction strong?

A) It guarantees victory
B) Large, representative sample size and clear majority pattern ✓
C) The candidate is popular
D) Surveys are always accurate

Explanation: Strong induction requires adequate sample size and representativeness; it still yields probability, not certainty.
